## เปิดและแก้ไข

เปิดโฟลเดอร์นี้ใน VS Code แล้วดับเบิลคลิก `index.html` เพื่อดูเว็บในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code

- `index.html` — ข้อมูลส่วนตัว ผลงาน ประสบการณ์ และเบอร์โทร
- `style.css` — สี ตัวอักษร และการแสดงผลบนคอม/มือถือ
- `script.js` — กดขยายภาพผลงาน
- `assets/` — รูปโปรไฟล์และภาพผลงาน เก็บในเครื่อง ไม่พึ่งลิงก์ภาพชั่วคราว

## อัปโหลด GitHub Pages

1. สร้าง repository ใน GitHub ของตัวเอง
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่ระดับบนสุด และคงโฟลเดอร์ `assets` ไว้
3. เปิด Settings → Pages → เลือก Deploy from a branch → เลือก `main` และ `/(root)` → Save
4. รอให้ GitHub Pages แสดงลิงก์เว็บ แล้วเปิดตรวจสอบ
5. ส่งลิงก์เว็บที่เปิดได้ พร้อมภาพแคปหน้าแรกตามโจทย์ (ลิงก์ repository อย่างเดียวไม่ใช่ลิงก์หน้าเว็บ)
